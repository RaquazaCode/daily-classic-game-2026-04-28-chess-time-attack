# Implementation Plan

## Goal

Build a deterministic local two-player chess MVP with a blitz-clock twist, browser hooks, and scripted verification.

## Milestones

1. Implement core chess state, legal move generation, and check resolution.
2. Add time-attack clocks, scoring, pause/reset, and DOM rendering.
3. Script a deterministic checkmate route for tests and Playwright capture artifacts.
4. Publish through the required git, GitHub, verification, and deployment flow.
